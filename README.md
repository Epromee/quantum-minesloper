# Q-Слопёр

**Q-Слопёр** — квантовый слоп-сапёр на базе классического «Сапёра». Создан как челлендж: завайбкодить игру без единой строчки кода руками. Фичи «Уверен» и «Квантовый ход» придумал **[Егор Промышленников](https://github.com/Epromee)**, при поддержке **Claude**, **Qwen** и **DeepSeek**.

Даже этот README — нейрослоп. Человеческий ввод остался только в промптах и в AGENTS.md, которые по сути тоже промпт.

## Правила

- **Короткое ЛКМ / тап** — открыть клетку.
- **Долгое нажатие (ЛКМ, палец) или ПКМ** — поставить или снять флажок.
- **Уверен** — у числа с полным набором флагов открывает остальных соседей автоматически.
- **Квант** — выбери две клетки: мина строго в одной из них. Пустая открывается, минную помечает флагом. Если мина в обеих или ни в одной — взрыв.
- **Победа** — открыть все клетки без мин.

## Уровни сложности

| Уровень  | Поле  | Мин |
| -------- | ----- | --- |
| Лёгкий   | 9×9   | 10  |
| Средний  | 14×12 | 30  |
| Сложный  | 16×14 | 50  |
| Адский   | 16×14 | 78  |

Числа правятся в `src/config.ts`.

## Авторство

- За основу взят классический «Сапёр» — это не авторская идея.
- Фичи **«Уверен»** (уверенное открытие) и **«Квантовый ход»** придумал **Егор Промышленников** — [github.com/Epromee](https://github.com/Epromee).
- Код сгенерирован нейросетями при поддержке **Claude**, **Qwen** и **DeepSeek**.
